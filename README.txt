Deployment checklist:
1. Upload the complete folder contents to the website document root (including assets/, robots.txt, sitemap.xml and favicon.svg).
2. Ensure HTTPS is enabled and the preferred host redirects to https://www.mindlead.co.in/ (the canonical host used in this build).
3. Submit https://www.mindlead.co.in/sitemap.xml in Google Search Console and Bing Webmaster Tools.
4. Verify ownership in Search Console, inspect the homepage and important service URLs, then request indexing.
5. Configure 301 redirects from any retired legacy URLs to their closest current equivalents at the hosting layer.
6. Add a real Search Console verification token only after obtaining it from the verified property; no placeholder token is included.
7. Confirm that the live contact details and externally hosted athlete image permissions are approved before launch.
